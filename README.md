# E-Commerce Order and Customer Analytics System

ITA0401 - Statistics with R Programming | 2026-27

A menu-driven R application for regional multi-category e-commerce operations and quarterly analytics.

## Features
- Customer registration/search
- Product catalogue and inventory updates
- Order placement and cancellation with stock rollback
- S3 Customer, Product and Order classes
- Category-specific discount dispatch
- Input validation and error handling
- CSV persistence and exports
- Quarterly revenue/category/customer/product analytics
- Low-stock alerts
- Correlation and linear regression
- Decision-tree classification
- ggplot2 visual reports

## Categories
Electronics, Fashion, Home & Kitchen, Books & Stationery.

## Run
Install R 4.5+ and run `source("app.R")`. The application installs missing packages automatically, loads demo data, and presents a numbered menu.

See the assignment document for the detailed requirements and methodology.
